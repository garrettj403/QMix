2.3. qmix.circuit module

This module contains classes and functions to describe the embedding circuit.

Description:

In experimental systems, SIS junctions are embedded within complex RF networks. These networks are referred to as the embedding circuit. Since all of the components in these embedding circuits are linear, the embedding circuit can be reduced to a Thevenin equivalent circuit, with one for each tone and harmonic.

To fully describe the embedding circuit, 3 bits of information are needed for each signal that is applied to the junction:

  1. the frequency of the applied signal,

  2. the Thevenin voltage of the embedding circuit at this freq., and

  3. the Thevenin impedance of the embedding circuit at this freq.

The main class in this module (EmbeddingCircuit) allows the user to build an embedding circuit in the proper format. MultiJunctionCircuit does the same for several junctions in one network: a multi-port Thevenin equivalent (a vector of voltages and an impedance matrix) for each tone and harmonic.

class qmix.circuit.EmbeddingCircuit(num_f=1, num_p=1, vb_min=0, vb_max=2, vb_npts=201, fgap=None, vgap=None, rn=None, name='')

Bases: object

Class for building and describing the embedding circuit.

This includes the frequencies, Thevenin voltages and Thevenin impedances of all signals applied to the junction.

Note

Unless specified otherwise, all input values are normalized. The voltages are normalized to the gap voltage, resistances are normalized to the normal-state resistance, currents are normalized to gap current, and frequencies are normalized to the gap frequency. Refer to the argument descriptions below to see if the value should be normalized or not.

Creating an instance of this class will set the sizes and data types of all of the class attributes, but the actual values will need to be set manually. In this way, this class is sort of like a fancy struct. The class attributes that have to be set manually are:

  • freq: frequencies (normalized to the gap frequency)

  • vt: Thevenin voltage (normalized to the gap voltage)

  • zt: Thevenin impedance (normalized to the normal resistance)

See the attribute descriptions below for information about how to do this.

Example

Here we will create an instance of the embedding circuit class with 2 tones and 3 harmonics:

>>> cct1 = EmbeddingCircuit(2, 3, name='Test 1')
>>> print(cct1)
Embedding circuit (Tones:2, Harmonics:3): Test 1

Once initialized, we can begin defining the properties of the embedding circuit. I normally start with the frequencies:

>>> cct1.freq[1] = 0.30  # first tone
>>> cct1.freq[2] = 0.32  # second tone

Then, we have to set the voltages and impedances for all of the different signals. For example, for the 1st harmonic of the 1st tone:

>>> cct1.vt[1,1] = 0.5             # Thevenin voltage
>>> cct1.zt[1,1] = 0.3 + 1j * 0.1  # Thevenin impedance

This has to be done for each signal (a total of 6 times in this case).

In order to use non-normalized values (e.g., set the available power of a signal in units [W]), we need to define the electrical properties of the junction during initialization. For example:

>>> cct2 = EmbeddingCircuit(1, 1, vgap=2.8e-3, rn=14.)

You can now set the frequencies. E.g.:

>>> cct2.set_freq(250, f=1, units='GHz')
>>> round(cct2.freq[1], 4)
0.3693

Once an impedance has been set, you can also set the power of the signal using absolute units. Here we will set the available power for the first harmonic of the first tone to 10 nW (10e-9 W).

>>> cct2.zt[1,1] = 0.5
>>> cct2.set_available_power(10, 1, 1, 'nW')

And we can then display this power in units [dBm].

>>> cct2.available_power(1, 1, 'dBm')
-50.0

freq

An array for the frequencies normalized to the gap frequency. This is a 1-dimensional array of real numbers. It contains the frequencies of all of the fundamental tones that are applied to the junction. The normalized frequency is equivalent to the normalized photon voltage. Note that this array is 1-based, meaning that the frequency of the 1st tone is found in .freq[1]. (The index represents the tone number.) This attribute must be set after initialization!

class qmix.circuit.MultiJunctionCircuit(num_j=2, num_f=1, num_p=1, vb_min=0, vb_max=2, vb_npts=201, fgap=None, vgap=None, rn=None, name='')

Bases: object

Embedding circuit for several junctions in one linear network.

With num_j junctions, the embedding circuit at each tone and harmonic is a num_j-port Thevenin equivalent: a vector of open-circuit voltages and an impedance matrix. The voltages across the junctions satisfy:

vj[j, f, p] = vt[j, f, p] - sum_l zt[j, l, f, p] * ij[l, f, p]

where ij[l] is the tunneling current of junction l (out of the network, into the junction). The coupling between the junctions (e.g., a twin-junction tuning circuit, or a series array) is in the off-diagonal elements of zt. qmix.network.set_thevenin sets vt and zt from an S-parameter network.

Note

The junction axis is first in all arrays, and the junctions are numbered from 0: vt[j], zt[j, l], vb[j] and vj[j] (from harmonic_balance) have the same shape as for a single junction. The tone and harmonic axes are 1-indexed as in EmbeddingCircuit.

All values are normalized, with one gap voltage and normal-state resistance for all junctions (the junctions are assumed to be made of the same materials). Junctions can have different areas (area, relative to the junction that defines rn): the tunneling current of junction j is area[j] times the current from its response function, i.e., its normal resistance is rn / area[j]. The response function can also be different for each junction (pass a list to harmonic_balance or qmix.qtcurrent.qtcurrent).

By default, each junction is voltage biased: its DC voltage is set by vb[j], and all junctions get the same bias sweep (a 1-D array is used for all junctions). For N identical, identically pumped junctions in series, cct.vb = vb / N is enough.

DC bias network: otherwise (e.g., a series array of junctions with different areas or different pumping, or a bias resistor), the DC voltages depend on the DC tunneling currents. A linear DC network (set_dc_network, or set_series_bias for series strings) adds num_j equations:

sum_l dc_a[r, l] * v0[l] + sum_l dc_b[r, l] * i0[l] = dc_rhs[r, i]

between the DC voltages v0[j] and the DC tunneling currents i0[j] (including area). harmonic_balance then solves for the DC voltages too, and returns them along with the junction voltage (vj, vb = harmonic_balance(...)); vb is only the initial guess. Set cct.vb = vb before using other functions (e.g., qmix.qtcurrent.qtcurrent).

Example

Two junctions (a twin-junction circuit) with one tone:

>>> cct = MultiJunctionCircuit(2, 1, 1, vb_npts=51)
>>> cct.freq[1] = 0.33
>>> cct.vt[:, 1, 1] = [0.4, 0.3j]
>>> cct.zt[:, :, 1, 1] = [[0.5, 0.1j], [0.1j, 0.4 - 0.2j]]
>>> print(cct)
Multi-junction embedding circuit (Junctions:2, Tones:1, Harmonics:1)

2.4. qmix.harmonic_balance module

This module contains functions to perform harmonic balance of non-linear SIS mixer circuits.

Description

Each signal that is applied to an SIS junction can be represented by a Thevenin equivalent circuit (see qmix.circuit). This circuit will then induce a voltage across the SIS junction. The exact voltage that is induced depends on the impedance of the SIS junction. However, this impedance changes depending on the other signals that are applied to the junction.

Harmonic balance is a procedure to solve for the voltage across the SIS junction for each signal that is applied to the junction. This techniques uses Newton’s method to find the solution numerically.

Several junctions in one embedding network (qmix.circuit.MultiJunctionCircuit) are solved together: the unknowns are the voltages of all junctions, and the Jacobian couples them through the off-diagonal Thevenin impedances. Since the current of each junction only depends on its own voltage, the derivatives of all junctions’ currents are found from the same perturbed voltages, so a new Jacobian costs 2 * num_n current calculations per junction (as for one junction).

2.5. qmix.network module

This module contains a class for linear networks described by scattering parameters (S-parameters), e.g., from electromagnetic simulations (HFSS) or measurements (VNA), and functions to read them from Touchstone files.

Description:

QMix describes the embedding circuit of the junction by its Thevenin equivalent at each frequency (qmix.circuit.EmbeddingCircuit). The Network class here is a way to get there from a more detailed description of the circuit: S-parameter networks can be connected to each other (Network.connect) and terminated (Network.terminate), and the impedance seen at one of the ports (e.g., the port where the junction sits) follows from Network.impedance. embedding_impedance wraps this into a function of frequency, including the junction’s capacitance, which can be used for the embedding impedances at the sidebands (e.g., qmix.exp.PumpedData.mixer_noise). thevenin also gives the Thevenin voltage when a source (e.g., the LO) drives another port, and set_thevenin puts both into a qmix.circuit.EmbeddingCircuit, so that the S-parameters drive the harmonic balance directly. With a list of junction ports, both give the multi-port Thevenin equivalent for several junctions (qmix.circuit.MultiJunctionCircuit).

Typical workflow (an RF tuning circuit with the junction at port 1, the RF input at port 2 and the IF output at port 3):

tuner = read_touchstone('tuner.s3p')
finline = read_touchstone('finline.s2p')
rf = tuner.connect(2, finline, 2)            # ports: junction, IF, waveguide
z_emb = embedding_impedance(rf, 1, cap=120e-15, terminations={3: 288.})
z_emb(230e9)                                 # in ohms

# LO with an available power of 50 nW at the waveguide port (port 3)
cct = EmbeddingCircuit(1, 1, vgap=2.7e-3, rn=14.)
cct.freq[1] = 230e9 / cct.fgap
set_thevenin(cct, rf, f=1, p=1, port=1, source_port=3, power=50e-9,
             cap=120e-15, terminations={2: 50.})

Note

Waves and reference impedances. The S-parameters are defined with power waves (Kurokawa, 1965), a = (V + Z_ref I) / (2 sqrt(Re Z_ref)) and b = (V - Z_ref^* I) / (2 sqrt(Re Z_ref)), with one reference impedance per port and frequency. For real reference impedances (the usual case), these are the usual traveling waves. Network.renormalize changes the reference impedances.

Ports are numbered from 1, as in Touchstone files. Frequencies are in [Hz] and impedances in [ohms] (not normalized), since these networks come from outside of QMix.

2.6. qmix.qtcurrent module

This module contains functions to calculate the quasiparticle tunneling currents passing through an SIS junction.

Description:

Given the voltages applied across an SIS junction, the quasiparticle tunneling currents can be calculated using multi-tone spectral domain analysis (MTSDA; see references in online docs).

Two methods are available for the summation over the phase factor coefficients (Eqn. 5.25 in Kittara’s thesis):

  • 'direct': the response function is interpolated at every combination of the summation indices (interpolate_respfn), and the sum is evaluated directly. The size of this matrix, and the time per current calculation, scale with the product of (2 * num_b + 1) over all tones.

  • 'fourier': the response function is represented by a (windowed) Fourier series, so that the shift in its argument factorizes into one term per tone. The cost then scales with the sum of (2 * num_b + 1) over all tones, and no large matrix is needed. This makes 5+ tones (or large num_b) tractable. The accuracy is limited by the smoothness of the response function splines: ~1e-7 (relative to the direct method) with the default cubic splines, ~1e-9 or better with spline_order=5 (see qmix.respfn.RespFn). It is not suitable for RespFnPerfect without smearing.

By default (method='auto'), the direct method is used unless the interpolated response function matrix would be larger than MAX_RESP_MATRIX_BYTES.

The current at an output frequency is the sum over all combinations of tone indices (a_1, …, a_F) with a_1 * f_1 + … + a_F * f_F equal to that frequency (Eqn. 5.36). All combinations with |a_f| <= num_p are included. When the tones are commensurate (e.g., LO, USB, LSB and IF), combinations with larger indices can also land on the output frequency, some of them first order in the signals (e.g., 2 * LO - LSB = USB). These are included if an upper bound on their contribution exceeds MIXING_TOL times the size of that current (see qtcurrent).

Note

This code is largely based on P. Kittara’s 2002 DPhil thesis (see references in online docs). I include some inline comments to refer to specific equations.

Also, all of the values in this module are normalized, i.e., voltages are normalized to the gap voltage, frequencies are normalized to the gap frequency, etc.

2.7. qmix.respfn module

This module contains classes to represent the response function of the SIS junction.

There are several different types of response function classes:

  • Response functions generated directly from I-V data:

    • RespFn: This is the base class for all of the other response function classes. This class will generate a response function based on a DC I-V curve (i.e., DC voltage and current data). Note that this class assumes that you have “pre-processed” the data. This means that it will use the voltage and current data to generate the interpolation directly. Normally, you want to have more data points around curvier regions in order to minimize how much time the interpolation takes. If you haven’t done this, it is a good idea to use RespFnFromIVData instead.

    • RespFnFromIVData: This class will generate a response function based on a DC I-V curve (i.e., DC voltage and current data). Unlike RespFn, this class will resample the response function in order to optimize the interpolation.

  • Response functions generated from I-V curve models:

    • RespFnPerfect: This class will generate a response function based on an ideal DC I-V curve (i.e., the subgap current is exactly zero below the gap voltage and exactly equal to the bias voltage above the gap, assuming normalized values). This DC I-V curve has an infinitely sharp transition. Note however that you can smear the transition using the v_smear argument. This will convolve the ideal reasponse function with a Gaussian distribution, allowing you to control the sharpness of the transition.

    • RespFnPolynomial: This class will generate a response function based on the polynomial model from Kennedy (1999). The order of the polynomial controls the sharpness of the transition, so this class can be used to simulate the effect of the transition’s sharpness (e.g., how does the gain change when the gap is more or less sharp?).

    • RespFnExponential: This class will generate a response function based on the exponential model from Rashid et al. (2016). This model is very similar to RespFnPolynomial, except that you can include a leakage current (i.e., a finite subgap resistance).

Upon initialization, these classes will:

  1. Load or calculate the DC I-V curve (which is the imagainary part of response function).

  2. Calculate the Kramers-Kronig transform of the DC I-V curve (which is the real part of the response function).

  3. Setup the density of the data points to optimize interpolation.

    • The response function needs enough data points that it can be interpolated accurately, but at the same time, not so many points that the interpolation takes too long.

  4. Calculate cubic spline fits for the I-V curve and the KK transform.

    • Doing this once at the start allows the data to be interpolated very quickly later on.

Once initialized, the classes allow the user to interpolated the DC I-V curve, the KK transform, the derivative of the I-V curve, the derivative of the KK transform, and the response function (a complex value). These classes are optimized to interpolate very quickly.

Examples

For a quick example, we will generate a response function using the polynomial model, with polynomial order 50:

>>> resp = RespFnPolynomial(50, verbose=False)

You can then interpolate the DC I-V curve and the KK transform:

>>> bias_voltage = np.array([0.5, 1.0, 2.0])
>>> dc_current = resp.idc(bias_voltage)
>>> np.around(dc_current, 1)
array([0. , 0.5, 2. ])
>>> kk_current = resp.ikk(bias_voltage)
>>> np.around(kk_current, 1)
array([-0.5,  1.1,  0.1])

You can also interpolate the response function directly, which is a complex array:

>>> resp = resp(bias_voltage)
>>> np.around(resp, 1)
array([-0.5+0.j ,  1.1+0.5j,  0.1+2.j ])

Here, the real part is the KK transform (same as the previous kk_current results) and the imaginary part is the DC I-V curve (same as the previous dc_current results).

2.8. qmix.small_signal module

This module contains functions for the small-signal analysis of SIS mixers (Tucker theory).

Description:

In a heterodyne mixer, a strong local-oscillator (LO) signal pumps the junction, and weak signals at the sidebands of the LO harmonics are converted to the intermediate frequency (IF) and vice versa. If the weak signals are small enough, they are linearly related by the small-signal (conversion) admittance matrix Y (Tucker, 1979; Tucker and Feldman, 1985; see references in online docs):

I_m = sum_n Y[m, n] V_n

where V_m and I_m are the junction voltage and current phasors at sideband m, which has the frequency m * f_lo + f_if (m = -num_sb … num_sb). Sideband 0 is the IF; sideband p > 0 is the upper sideband (USB) of LO harmonic p; sideband -p < 0 is the lower sideband (LSB) of LO harmonic p.

The LO state comes from a single-tone harmonic balance (or any junction voltage at the LO and its harmonics). The admittance matrix then gives the response to weak signals at any IF frequency, without a multi-tone simulation. The results agree with multi-tone simulations in the limit of weak signals.

Typical workflow:

vj = harmonic_balance(cct, resp)                  # LO only
y = admittance_matrix(vj, cct, resp, f_if)
zt = sideband_impedances(z_if, z_usb, z_lsb)
gain = conversion_gain(y, zt, 1)                  # USB -> IF

The shot noise of the junction (including its thermal and quantum limits) is described by the current noise correlation matrix H (Tucker and Feldman, 1985), from which the noise temperature of the mixer follows:

h = noise_matrix(vj, cct, resp, f_if, temp, vgap)
tn = noise_temperature(y, h, zt, vgap, 1)         # SSB, USB input

Several junctions (qmix.circuit.MultiJunctionCircuit): admittance_matrix and noise_matrix return one matrix per junction (junction axis first). The junctions are coupled by the embedding network, which is described at each sideband by its impedance matrix over the junction ports and one external port (sideband_networks): the port of the RF source (or image termination) at the RF sidebands, and of the IF load at the IF. The external port is terminated by z_ext (the source or load impedance). network_gain, network_output_noise and network_noise_temperature then give the gain and noise between external ports, including the thermal noise of a lossy network. This also works for one junction (e.g., to include the loss of its tuning circuit):

vj = harmonic_balance(cct, resp)                  # several junctions
y = admittance_matrix(vj, cct, resp, f_if)        # y[j, m, n, i]
h = noise_matrix(vj, cct, resp, f_if, temp)
z_net = sideband_networks(z_if, z_usb, z_lsb)     # (J+1)-port matrices
z_ext = sideband_impedances(r_if, r_rf, r_rf)     # terminations
gain = network_gain(y, z_net, z_ext, 1)
tn = network_noise_temperature(y, h, z_net, z_ext, vgap, f_lo, f_if, 1,
                               temp=temp, temp_ext=temp)

Note

Phasors at negative frequencies. For m < 0, the frequency m * f_lo + f_if is negative. The phasors V_m, I_m, the source voltages and the impedances at these sidebands are the complex conjugates of the values at the positive (physical) LSB frequency |m| * f_lo - f_if. sideband_impedances and sideband_voltages take the physical values and do this conversion; lsb converts the results back.

Indexing. Arrays over sidebands are stored in natural order: sideband m is at index m + num_sb.

All values are normalized, as in the rest of QMix: voltages to the gap voltage, currents to the gap current, admittances to 1 / Rn, impedances to Rn and frequencies to the gap frequency. Phasors are peak amplitudes.

2.9. qmix.superconductor module

This module contains functions and classes for the surface impedance of superconducting and normal metal films, for use in transmission lines (e.g., qmix.network.microstrip).

Description:

The tuning circuits of SIS mixers are usually made from superconducting films (e.g., Nb or NbTiN). Below the gap frequency, these films have a small surface resistance but a large kinetic inductance, which slows the waves on the lines by ~10-20% and therefore shifts the frequencies at which the tuning circuit resonates. Above the gap frequency (~700 GHz for Nb), photons break Cooper pairs and the films become lossy.

The complex conductivity of a superconductor is calculated with the Mattis-Bardeen theory in the local (dirty) limit (mattis_bardeen), using the BCS temperature dependence of the energy gap (energy_gap). The surface impedance of a film of finite thickness (or of a stack of films) follows from the conductivity by treating the film as a section of transmission line (film_impedance).

The calculations are done by the mattisbardeen package (https://github.com/garrettj403/Mattis-Bardeen); this module adapts it to QMix (film objects for qmix.network.microstrip, and the gap voltage at T = 0 as the material parameter). Its physical constants come from mattisbardeen.sc (scipy.constants), read when the functions are called.

The film classes (NormalFilm, SuperconductingFilm and Multilayer) bundle the material parameters, so that they can be passed to the transmission line functions in qmix.network:

nb = SuperconductingFilm(vgap=2.8e-3, tc=9.2, rho_n=5e-8, thickness=300e-9)
nb.zs(500e9, 4.2)                 # surface impedance, in [ohms]

Note

Unlike the rest of QMix, the values here are not normalized: frequencies are in [Hz], temperatures in [K], voltages in [V], lengths in [m], resistivities in [ohm m] and conductivities in [S/m].

Complex values use the engineering convention exp(+j w t), as for the impedances in the rest of QMix: an inductive reactance is positive, and the conductivity of a superconductor is sigma1 - j sigma2.
